◆ Power BI – Sales Forecasting Analysis Project
◆ Project Overview

This project focuses on analyzing and forecasting sales performance using Power BI. It includes data cleaning, modelling, time-series forecasting, DAX calculations, and dashboard development. The goal was to understand historical sales trends, identify top-performing areas, and forecast future sales.

◆ Objectives of the Project
◇ Clean and prepare raw sales data
◇ Build a proper data model with relationships
◇ Analyze historical sales performance
◇ Identify top products, customers, and regions
◇ Measure revenue, profit, and growth trends
◇ Create KPIs for key business metrics
◇ Apply Power BI’s forecasting tools
◇ Build a fully interactive dashboard
◆ Project Work Completed
■ 1. Data Cleaning and Preparation
▶ Removed blanks, nulls, and invalid values
▶ Standardized all date formats
▶ Added Month, Quarter, Year columns
▶ Created and marked a Date Table
▶ Assigned correct data types for all fields
■ 2. Data Modelling
▶ Used a star schema (FactSales + Dimension Tables)
▶ Defined one-to-many relationships
▶ Improved performance with a clean model structure
▶ Marked the date table for time intelligence
■ 3. DAX Measures Created
▶ Total Sales
▶ Total Quantity Sold
▶ Average Sales per Customer
▶ Year-over-Year Growth
▶ Month-over-Month Growth
▶ Profit and Profit Margin
▶ Forecasting metrics using analytics pane
■ 4. Exploratory Sales Analysis
▶ Trend analysis for monthly, quarterly, yearly sales
▶ Top-selling products and categories
▶ Region-wise and country-wise sales performance
▶ Customer purchase behaviour insights
▶ Comparison of revenue and profit
▶ Seasonality and recurring patterns
■ 5. Sales Forecasting
▶ Used Power BI Analytics forecasting model
▶ Selected forecast duration (6 or 12 months)
▶ Applied confidence intervals
▶ Identified sales trends for upcoming months
▶ Interpreted future sales growth based on historical data
■ 6. KPI Indicators
▶ Total Sales
▶ Total Orders
▶ Total Customers
▶ Average Order Value
▶ Forecasted Sales

These KPIs allowed quick business performance monitoring.

■ 7. Final Power BI Dashboard

The dashboard included:

▶ Sales trend line with forecasting
▶ Sales by product
▶ Sales by region/country
▶ Top 10 customers
▶ Profit vs Sales chart
▶ Category/Sub-category performance
▶ Interactive filters and slicers
◆ Tools and Technologies Used
◇ Microsoft Power BI
◇ Power Query Editor
◇ DAX
◇ Time-Series Forecasting
◇ Data Modelling Techniques
◆ Key Insights
◇ Clear seasonality in monthly sales
◇ Small number of products contribute major revenue
◇ Some regions underperform and need improvement
◇ Repeat customers significantly influence sales stability
◇ Forecast results show consistent future growth
◆ Conclusion

This project delivers a complete sales analysis along with accurate forecasting for future months. It highlights strong skills in Power BI such as data cleaning, modelling, DAX, forecasting, and dashboard storytelling. This is suitable for GitHub portfolio, resumes, and interviews.
